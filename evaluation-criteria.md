# Документація та методичні матеріали

Ця папка містить усі методичні матеріали, потрібні для написання та перевірки дипломної роботи.

## Що тут є

| Файл | Опис | Для кого |
|------|------|----------|
| [`Методичні_вказівки_до_виконання_ДП.pdf`](Методичні_вказівки_до_виконання_ДП.pdf) | **Офіційна методичка** (71 стор.) — першоджерело | усі |
| [`methodology.md`](methodology.md) | Огляд методички та індекс цих файлів | усі |
| [`structure-requirements.md`](structure-requirements.md) | Вимоги до структури роботи: розділи, обсяги, обов'язкові елементи | студенти + рецензент |
| [`dstu-requirements.md`](dstu-requirements.md) | Вимоги ДСТУ 3008–2015 до оформлення: шрифти, поля, рисунки, таблиці, посилання | студенти + рецензент |
| [`evaluation-criteria.md`](evaluation-criteria.md) | Критерії оцінювання роботи та захисту (100-бальна шкала) | студенти + рецензент |
| [`review-checklist.md`](review-checklist.md) | Покроковий чек-лист рев'ю | рецензент (Claude використовує під час review) |

## Як читати ці документи

**Студентам:** прочитайте `methodology.md` → `structure-requirements.md` → `dstu-requirements.md` → `evaluation-criteria.md` **перед тим**, як почати писати роботу. Більшість зауважень виникає через невідповідність цим документам. Офіційна методичка у PDF — джерело істини при будь-яких суперечностях.

**Рецензенту (Claude):** під час перевірки роботи звертайся до `review-checklist.md` як до основного інструменту. Він посилається на інші документи у цій папці.

## Як вносити зміни до методичних матеріалів

Зміни у `docs/` робить лише науковий керівник (власник репозиторію). Студенти не змінюють файли в цій папці.
